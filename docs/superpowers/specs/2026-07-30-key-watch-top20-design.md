# 重点观察池改为前 20 名设计说明

## 背景

当前规则将 `重点观察池` 定义为 `total_score >= 80`。全市场实跑后，重点观察池仅产生 1 只股票，无法满足“先快速收敛出一小批重点跟踪标的”的使用目标。

用户已确认将分池规则调整为：

- `重点观察池`：通过硬过滤且成功出总分的股票中，按总分排名前 20 名直接列入
- `观察池`：其余通过硬过滤且成功出总分的股票
- 被硬过滤的股票：不进入任何池子

## 目标

本次变更只调整分池规则，不改动以下逻辑：

- 硬过滤规则
- 各维度打分逻辑
- `total_score` 计算逻辑
- `global_rank` / `industry_rank` 排名逻辑

## 实现方案

### 1. 配置层

将池子配置从分数阈值切换为名次阈值：

- 新增 `pool_thresholds.key_watch_top_n = 20`
- 保留旧的 `key_watch_min_score` 不再作为实际分池依据，后续可移除或仅作历史兼容

### 2. 评分层

在 `scorecard.py` 中保持现有流程：

1. 计算行业分位数与各维度分数
2. 计算 `total_score`
3. 计算 `global_rank` 与 `industry_rank`
4. 基于 `global_rank` 重新设置 `current_pool`

具体分池规则：

- 若 `is_filtered = true` 或 `total_score is null`，则 `current_pool = null`
- 若 `global_rank <= 20`，则 `current_pool = "重点观察池"`
- 否则 `current_pool = "观察池"`

## 边界处理

### 同分处理

本次采用固定 20 名方案，不做“并列扩容”：

- 仍按现有排序规则生成 `global_rank`
- 只要 `global_rank <= 20` 就进入重点观察池
- 第 20 名之后即使同分，也归入观察池

### 过滤股票

过滤股票不参与重点观察池名额竞争，也不应被标记为观察池。

## 测试要点

需要补充或更新以下测试：

- 前 20 名进入重点观察池
- 第 21 名进入观察池
- 被过滤股票不占用前 20 名名额
- 总分排序与排名逻辑不因分池规则变化而改变

## 风险与影响

本次变更会显著增加重点观察池稳定输出能力，但也意味着：

- `重点观察池` 不再代表“绝对达到某分数线”
- 它变为“本轮样本中的相对前 20 名”

这与当前产品目标是一致的：先快速收敛出一组最值得优先看的股票，再交给用户做进一步分析。
